## 二、历史背景与军事设定

### 时间线
1942年太平洋战争早期（1941年底-1943年初）

### 核心战役
- **珊瑚海海战（1942年5月）**：指挥约克城号（CV-5）和列克星敦号（CV-2）对抗日军入侵舰队
- **中途岛海战（1942年6月）**：指挥企业号（CV-6）和约克城号伏击日军机动部队（Kido Butai）

### 历史还原重点
- 模拟了人类历史上第一次**超视距航母对决**——双方水面舰队从未互相目视发现
- 还原了当时航母的**直通甲板设计**带来的操作困境
- 忠实再现了通信延迟、侦察报告不确定性等**战争迷雾**

## 三、游戏机制详解

### 3.1 界面系统

#### 指挥站（Command Stations）

| 指挥站 | 快捷键 | 功能 |
|--------|--------|------|
| FLAG PLOT | F1 | 旗舰指挥室，默认视图，交互式指挥中心 |
| STRATEGIC MAP | F2 | 2D战略态势图，规划航线/速度/编成/航空任务 |
| FLEET PLOT | F3 | 舰队信息屏幕，查看各舰队状态 |
| FORMATION EDITOR | F4 | 编队编辑器，拖拽调整阵位 |
| DEFENSIVE AIR OPS | F5 | 防空作战，设置CAP巡逻 |
| FIGHTER DIRECTION | F6 | 战斗机指挥屏幕，实时空防指挥 |
| AIRCRAFT ROSTER | F7 | 飞机名册，查看甲板/机库飞机状态 |
| DECK TIMELINE | F7×2 | 甲板时间线，查看即将进行的航空作业 |
| MISSIONS | F8 | 任务名册，查看已下达任务和战斗报告 |
| SQUADRONS | F8×2 | 中队名册，查看航空队统计数据 |

#### 视图系统（Views）

| 视图 | 快捷键 | 功能 |
|------|--------|------|
| WORLD 3D VIEW | ENTER | 轨道式3D视图，可查看任意单位 |
| BINOCULAR/BRIDGE VIEW | NUMPAD 8 | 第一人称视角（舰桥/机头） |
| TACTICAL VIEW | SPACE | 简化3D战场视图（类似Homeworld） |

#### 界面控制
- `TAB`：隐藏所有界面模块（包括鼠标光标）
- `RETURN`：展开/折叠左侧面板
- `HOME`：展开/折叠右侧面板
- `WASD`：移动摄像机（第一人称射击风格）
- `SHIFT+WASD`：慢速移动
- `R/F`：改变高度
- `右键`：环顾四周
- `滚轮`：缩放
- `PGUP/PGDN`：切换单位
- `双击左键`：以该单位为中心（包括敌方单位）

### 3.2 舰艇系统

#### 舰艇分类

| 类型 | 代号 | 角色 | 本场景舰艇 |
|------|------|------|-----------|
| 航母 | CV | 核心打击力量 | USS Yorktown (CV-5), USS Lexington (CV-2) |
| 重巡洋舰 | CA | 防空/反舰护航 | Northampton, Chester, Portland, Minneapolis |
| 驱逐舰 | DD | 反潜/救援/外圈护航 | 多艘 Fletcher 级 |

#### 舰艇详细参数

**USS Lexington (CV-2)**
- 美国海军第一艘真正的舰队航母
- 基于战列巡洋舰舰体建造（世界上最长的军舰）
- 弱点：开放式机库侧面、第三升降机
- 优势：8英寸巡洋舰炮已换装为1.1英寸"芝加哥钢琴"速射炮 + 大量20mm和.50英寸防空炮
- 特点：转弯笨拙，但能承受大量损伤

**USS Yorktown (CV-5)**
- 约克城级首舰，企业号(CV-6)和大黄蜂号(CV-8)的姊妹舰
- 美国海军最先进的航母类型
- 下一代埃塞克斯级航母的蓝图
- 优势：韧性、速度、续航力、飞机容量、有效防空保护

#### 编队层级

```
Task Force (TF) — 特遣舰队（最大单位）
├── Task Group (TG) — 特遣大队
│   └── Task Unit (TU) / Division — 特遣小队/分队
│       └── Individual Ships — 单舰
```

- **分队（Division）**：同类型舰艇组成（如驱逐舰分队、巡洋舰分队）
- **大队（Task Group）**：可包含不同类型的分队
- **舰队（Task Force）**：最高层级，可重组/拆分/合并

旗舰标识：
- 一颗星：分队旗舰
- 两颗星：大队旗舰
- 三颗星：舰队旗舰

#### 编队编辑
- 在战略地图(F2)上右键点击舰队图标打开对话框
- 拖拽编队/舰艇重新组织
- 使用距离圆圈使编队整齐
- 右键编队可采用战术预设（如纵列编队）
- 旗舰分队不能移离编队中心
- 编队命令立即下达，但执行需要时间

### 3.3 飞机系统

#### 美军飞机

| 机型 | 代号 | 角色 | 特点 |
|------|------|------|------|
| F4F-3 Wildcat | VF | CAP战斗机 | 4×.50英寸机枪，耐用，无折叠翼（仅18架） |
| SBD Dauntless | VS/VB | 侦察/俯冲轰炸机 | 主要伤害输出，1942年100%日军航母损伤由其造成 |
| TBD Devastator | VT | 鱼雷机 | 已过时，Mk13 Mod 0鱼雷勉强可用，Mod 1极不可靠 |

**F4F Wildcat 详细**：
- 纸面上应该平庸，但1942年面对零式保持正胜率
- 秘密：无与伦比的耐用性 + 4×.50英寸机枪致命火力
- 弱点：无折叠翼，早期战斗机中队仅约18架
- 意味着永远人手不足：保护轰炸机 vs 保护舰队只能选一

**SBD Dauntless 详细**：
- "Slow But Deadly"（慢但致命）
- 1942年造成日军航母100%损伤
- 侦察中队(VS)和轰炸中队(VB)都有
- 也是主要侦察平台
- 数量有限，需要明智管理

**TBD Devastator 详细**：
- 三种飞机中最过时的
- Mk13 Mod 0鱼雷在1942年初表现尚可
- 新Mod 1鱼雷极不可靠
- 5月8日事件中鱼雷中队基本未受损（日军集中攻击俯冲轰炸机）
- 导致中途岛前的虚假安全感，随后在中途岛全军覆没

#### 日军飞机

| 机型 | 代号 | 角色 | 特点 |
|------|------|------|------|
| A6M2 Zero | - | 战斗机 | 传奇，航程/速度优势，但脆弱无自封油箱 |
| D3A Val | Kanbaku | 俯冲轰炸机 | 固定起落架，250kg半穿甲弹，灵活 |
| B5N2 Kate | Kanko | 鱼雷机 | 日军王牌，各方面优于TBD，极可靠鱼雷 |
| E13A Jake | - | 侦察水上飞机 | 巡洋舰弹射起飞，日军之眼 |

**A6M2 Zero 详细**：
- 1942年5月已是传奇，美军尚未真正长时间空战遭遇
- 纸面性能远超F4F
- 弱点：脆弱机体 + 无自封油箱 = 一旦被击中极易起火

**D3A Val 详细**：
- 类似德国斯图卡
- 不快，不喜欢被射击
- 载弹量仅SBD一半
- 250kg半穿甲弹：穿透一层装甲后在内部爆炸
- 也携带高爆弹：杀伤暴露人员

**B5N2 Kate 详细**：
- 日军武器库中的王牌
- 各方面优于TBD（除生存性外）
- 极可靠鱼雷，发射特性优秀
- 与俯冲轰炸机协同三维钳形攻击

**E13A Jake 详细**：
- 1942年世界最先进的侦察水上飞机之一
- 巡洋舰弹射起飞
- 虽然被战斗机拦截几乎必死，但会用最后时刻发送你的位置

#### 日军弱点
- 脆弱机体 + 无自封油箱
- 防空火力差：25mm弹匣供弹无法持续射击
- 5英寸高炮火力控制系统劣于美军
- 无雷达探测（美军航母已装备）

### 3.4 编队与编成

#### 标准编成
- 核心（Core）：CV、BB
- 护航（Screen）：CA、CL、DD
- 每艘主力舰需要3-4艘护航舰确保100%护航效率

#### 标准编成示例（1942年末）
```
2× CV（航母）
2× BB（战列舰）
2× CA（重巡洋舰）
9× DD（驱逐舰）
```

#### 速度限制
- 整个编队速度 = 最慢舰艇速度
- 护航的BB和CA必须能跟上CV速度

### 3.5 侦察系统

#### 侦察规划
- 右键点击战略地图上的TF17，选择上下文菜单
- 或点击AIR OPS TIMELINE右侧按钮
- 点击"CREATE NEW AIR SEARCH"开始规划

#### 搜索模式
- 搜索模式通常描述为扇形或饼图
- 每架飞机分配一个扇区
- 飞机通常（但不总是）以三角形或饼图方式返回
- 初始规划：选择飞机数量、所需航程、单架飞机搜索扇区宽度

#### 侦察技巧
- 经验法则：侦察机飞离潜在目标超过15-20英里不要期望结果
- 高度帮助看得更远，但可能在云层上方
- 舰艇在侦察机离开期间在移动——回收点基于当前航向和速度计算
- SBD和TBD配备归航信标系统，但可能找不到你

#### AIR OPS TIMELINE
- 显示当天剩余时间的航空作业
- 左侧选择相关航母，选择小时增量
- 起飞时间超过4小时需选择24小时增量
- 悬停在任务上时显示航路点和规划信息
- 蓝色箭头：计划起飞
- 红色箭头：计划回收

#### AIR PLOT 子站
- **AIRCRAFT ROSTER (F7)**：蓝色高亮显示准备中的飞机
- **DECK TIMELINE (F7×2)**：显示任务各阶段（准备/出发/回收）
- **MISSION ROSTER (F8)**：点击任务查看信息，可编辑，完成后可查看日志和报告
- **SQUADRON ROSTER (F8×2)**：查看航空队统计

### 3.6 CAP系统

#### CAP设置
- 进入DEFENSIVE AIR OPS屏幕(F5)
- 点击"CREATE NEW COMBAT AIR PATROL ZONE"
- 设置PATROL STRENGTH（巡逻强度）：每段巡逻飞机数
- 巡逻自动轮换：总飞机数 = 巡逻强度 × 2
- PATROL ALTITUDE：巡逻巡航高度
- 轮换间隔：单次巡逻在空中停留时间

#### 巡逻区域
- 在右侧标图区域设置
- 可移动角落点重新组织
- 拖拽中心点移动
- CAP巡逻沿方框外缘飞行
- 创建屏障CAP：制作非常窄的矩形
- 巡逻箱可随时修改
- 注意左上角比例尺

#### CAP注意事项
- CAP固定方位：相对于旗舰，独立于舰队机动
- 巡逻箱越远 → 实际巡逻时间越短 → 需要更多飞机维持巡逻
- 巡逻箱越远 → 对非轴向威胁重新引导时间越长

#### FDO（战斗机指挥官）
- FIGHTER DIRECTION SCREEN (F6)
- "FDO IN CHARGE"复选框：自动/手动切换
- 自动模式：AI处理威胁
- 手动模式：选择巡逻，点击目标指示攻击
- Bogeys（未识别目标）：黄色
- Bandits（敌方目标）：红色
- 可选显示图例获取更多信息

#### SCRAMBLE（紧急起飞）
- AIR OPS TIMELINE上的SCRAMBLE按钮
- 极端紧急情况使用
- 命令选定航母上所有未分配战斗机立即起飞
- 创建即时CAP巡逻区
- 代价：打乱所有正常航空作业
- 慎重使用：确保补救措施不比威胁更糟

#### 拦截矢量
- 引导拦截目标时，CAP巡逻和目标都显示直线
- 显示预期拦截点
- 如果目标不直线飞行，拦截点会移动

### 3.7 打击系统

#### 打击规划
- STRIKE PLANNER是SEARCH PLANNER的增强版
- 左侧剪贴板：更改参数
- 右侧剪贴板：实时信息，允许批准任务

#### 机型分配
- 选择航母开始打击作业
- 目前仅NAVAL ATTACK（海军攻击）任务可用
- 点击飞机类型旁的(+)按钮分配到打击包

#### 目标选择
- TARGET SELECTION：分配已知联系或留空
- 留空用于预排列打击（Pre-spotted strike）
- 预排列打击需在SPOTTING MODE中定义为"Pre-spotted"

#### SPOTTING MODE（排列模式）
- **Standard Time**：按设定出发时间紧密排列
- **Early Spotting**：提前排列，以其他航空作业为代价

#### DEPARTURE MODE（出发模式）
- **Deferred Departure**：打击元素等待彼此，作为整体前往目标区。编队完整性风险低，但续航力也低
- **Normal Departure**：快速元素在途中加入慢速元素。编队完整性风险高，但续航力更好
- Emergency Departure（未来版本激活）

#### LOADOUT PREFERENCE（挂载偏好）
- **Endurance**：携带较小攻击载荷，但续航力更好
- **Offensive Power**：更重更致命载荷优先，即使航程和续航力更小

#### 打击范围
- 地图上红色圆盘显示当前参数下的最大打击范围
- 航母编队总是在移动：现在超出范围的目标几小时后可能在范围内

### 3.8 损伤系统

#### 损伤报告
- 航母受损后，右侧面板显示简要损伤报告
- 悬停在不同元素上高亮显示模块损伤类型

#### 模块状态
| 状态 | 颜色 | 含义 |
|------|------|------|
| OK | 绿色 | 100%运作，未受损 |
| Disabled | 橙色 | 暂时失效，将恢复 |
| Damaged | 黄色 | 已修复但有负面效果 |
| Destroyed | 红色 | 毁坏，本场景无法修复 |

#### 损伤影响
- 模块修复时间随机化
- 关键模块（如舵）可能需要数小时修复
- 航空模块损伤影响航空作业能力
- 飞行甲板火灾暂停所有航空作业直到扑灭

### 3.9 胜利系统

#### 胜利评估
- 提供战术和战略双重评估
- 不仅看杀伤/损失比
- 游戏提供9种不同结果

#### 评估维度
- 是否完成战略目标（如击退第五航空战队）
- 是否造成大于己方的损失

#### 珊瑚海场景目标
- 主要目标：迫使敌方航母部队撤退，导致MO作战取消
- 不会因与对手达成相同结论（双方撤退）而受罚
- 高指挥部在敌方撤退时通知你，可选择继续战斗数小时或直接进入胜利屏幕

## 四、开局策略详解

### 4.1 04:00 — 开局机动
```
1. 调整航速：29+节
2. 调整航向：东/东南方向
3. 目的：远离敌方可能的巡逻区域，争取准备时间
4. 检查天气：向云层密集区域机动以隐蔽
5. 设置航路点：确保航母在黎明时（05:45）刚好逆风航行
```

### 4.2 04:30 — 打击规划（预排列）
```
1. 打开打击规划器
2. 为TF16（企业号/大黄蜂号）和TF17（约克城号）预设打击包
3. 选择机型：TBD鱼雷机 + SBD俯冲轰炸机 + 9+护航战斗机
4. 选择"Early Spotting"模式
5. 点击"X"关闭菜单 → 保持"Planning"状态
6. 不要点击"Take Off"！
```

### 4.3 04:45 - 05:00 — 黎明侦察
```
1. 使用巡洋舰水上飞机（SOC-1）执行首轮侦察
2. 绘制搜索扇区：覆盖日军机动部队可能区域
3. 重点覆盖南部和西部边缘（日军向中途岛移动方向）
4. 搜索半径：约600km，确保快速返回
```

### 4.4 05:00 - 05:45 — CAP建立
```
1. 从航母紧急起飞战斗机
2. 建立多层CAP巡逻区域
3. 交错高度：低空/中空/高空覆盖
4. 保留部分战斗机在甲板待命
5. 检查飞行甲板空间：确保预设打击包不超过单甲板容量
```

### 4.5 05:45 - 06:00 — 打击执行
```
1. 侦察机报告敌方航母位置
2. 打开打击规划器
3. 更新目标坐标（锁定新发现的敌方图标）
4. 点击"Greenlight/Launch"
5. 协调打击：确保护航战斗机与轰炸机同高度飞行
```

## 五、新手必知技巧

### 5.1 10个核心技巧

1. **逆风起降**：航母必须逆风航行才能起降飞机，提前手动调整航向
2. **先规划再侦察**：在侦察机起飞前就规划好打击包
3. **协调打击到达**：SBD和TBD同时到达目标
4. **3D视角技巧**：无选中时按3D按钮跳转到地图中心
5. **夜间东进**：开局向东高速机动，远离敌方巡逻区域
6. **不要一次全部起飞CAP**：保留待命战斗机
7. **善用Early Spotting**：提前排列打击包，发现目标后立即释放
8. **护航高度匹配**：护航战斗机与轰炸机同高度
9. **信任下属**：让船员自主规避鱼雷
10. **从简单开始**：先玩珊瑚海场景

### 5.2 常见新手错误

1. **单航母打击**：早期美军通信限制，每艘航母航空队需单独管理
2. **忽略手册**：游戏教程过于冗长，从主菜单右下角下载PDF手册
3. **打击时航母无保护**：把所有战斗机都派去护航
4. **甲板满载时被攻击**：甲板上满载燃料弹药的飞机被击中
5. **忽略天气**：不检查天气预报，不利用云层隐蔽
