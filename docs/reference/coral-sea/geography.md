## 水道与航行条件（PROBABLE，建模用）

- **乔马德水道**：路易西亚德间深水通道，攻略船队必经；西侧浅礁散布（Jomard Reefs）。
- 大堡礁外缘与澳东北沿岸：盟军岸基机扇面覆盖。
- 珊瑚海盆地：5/7-8 机动海域开阔深水，适合航母机动（depth 面元在战区包内）。
