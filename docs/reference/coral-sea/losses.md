## 战役后果（S7 复盘锚点）

1. **战略分水岭**：莫尔兹比港正面登陆放弃（MO 延期）——日军南进首次受挫。
2. **翔鹤重损 + 瑞鹤机队耗尽** → 两舰双双缺席中途岛（翔鹤在修、瑞鹤缺飞行队）。
3. 列克星敦损失使太平洋美军航母一度只剩 3 艘（企业/大黄蜂/约克城）。
4. 战果误判双向：美方以为多沉日舰（含误记 Ryukaku）；日方以为击沉 2 艘美航母——
   双向情报噪声是 S2/S3「误报-漏报」教学样本。
