# 中途岛指挥官 · 游戏规则文档

> 本文档是所有游戏机制的唯一真相来源。开发、测试、设计均以此为准。

---

## 一、游戏概要

**背景**：1942年6月4日，中途岛战役。玩家扮演 TF16 指挥官 Spruance。
**核心玩法**：通过自然语言与参谋团对话，下达侦察/航行/攻击命令。
**核心体验**：信息不对称 × 参谋性格偏差 × 时间压力。

---

## 二、时间系统

### 2.1 游戏时钟
- 起始时间：1942年6月4日 04:00 Z+12
- 时区：Z+12（中途岛时区）
- 每次推进：15分钟

### 2.2 动作点（AP）
| 回合类型 | AP 数 | 触发条件 |
|---------|-------|---------|
| 普通 | 3 | 默认 |
| 关键 | 5 | 接近敌军/战斗准备 |
| 紧急 | 2 | 被攻击/紧急情况 |

**消耗规则**：
- 和 NPC 对话：1 AP
- 下达命令：1 AP
- 推进时间：0 AP（但重置 AP）

## 三、地理系统

### 3.1 坐标系
- 参考点：中途岛 28.2°N, 177.4°W → hex (0, 0)
- 六边形网格：10nm/格，40格半径（400nm 范围）
- 地理坐标为主，hex 为显示辅助

### 3.2 初始位置
| 单位 | 位置 | 航向 | 航速 |
|------|------|------|------|
| TF16（Enterprise） | 31.5°N 176.0°W | 240° | 25kn |
| TF16（Hornet） | 31.5°N 176.0°W | 240° | 25kn |
| Kido Butai | 31.0°N 180.0°W | 110° | 20kn |
| 中途岛 | 28.2°N 177.4°W | — | — |

### 3.3 关键距离
- TF16 → 中途岛：~211nm
- Kido Butai → 中途岛：~216nm
- TF16 → Kido Butai：~207nm
- SBD 作战半径：167nm（无法覆盖 KB）

### 3.4 移动规则
- 每 tick（15分钟）按航向和航速移动
- 移动距离 = 速度 × 时间/60
- 使用大圆航线计算新位置
- 经度自动包裹到 [-180, 180]

## 五、侦察系统

### 5.1 侦察流程
```
玩家命令 → Browning 提出方案（propose_recon）
  → 玩家确认 → 飞机起飞（launch_scout）
  → PREPARING(15min) → OUTBOUND(45min) → SEARCHING(60min)
  → RETURNING(45min) → LANDED
```

### 5.2 搜索模式
| 模式 | 扇面宽度 | 检定基础值 | 适合场景 |
|------|---------|-----------|---------|
| sector（扇形） | 40° | +5 | 已知方向 |
| parallel（平行） | 120° | -5 | 未知方向 |
| grid（方格） | 60° | +0 | 怀疑区域 |

### 5.3 检测机制（骰子系统）
```
骰子检定 = d100 + NPC修正 + 情境修正

NPC修正: Browning.competence × 25 = +22
情境修正:
  - 距离 < 100nm: +10
  - 距离 > 150nm: -10
  - 扇形搜索: +5
  - 平行搜索: -5
```

### 5.4 五级侦察结果
| 骰值 | 结果 | 侦察效果 |
|------|------|---------|
| 95+ | 大成功 | 清晰识别（最小失真） |
| 70-94 | 成功 | 识别（标准失真） |
| 40-69 | 部分成功 | 看到大船，不确定类型 |
| 10-39 | 失败 | 漏报（没看到） |
| 9- | 大失败 | 被击落或严重误报 |

### 5.5 信息失真
- 方位误差：±5°
- 距离误差：±10%
- 数量少报：30% 概率少报 1-2 艘
- 大成功时：方位±2°，距离±5%，数量准确

### 5.6 报告延迟
- 基础延迟：20 分钟
- 距离因子：(距离/200) × 25 分钟
- 随机抖动：-5 到 +10 分钟
- 总延迟范围：20-55 分钟

### 5.7 飞机损失
| 条件 | 损失 | 原因 |
|------|------|------|
| 返航燃油 < 5% | 1-2 架 | 燃油耗尽坠海 |
| 返航途中 < 10% | 50% 概率 1 架 | 燃油不足 |
| 天气损失 | 5% 概率/架 | 恶劣天气 |
| 大失败检定 | 1 架 | 被敌方击落 |

## 六、骰子系统

### 6.1 核心机制
```
基础骰 = d100 (1-100)
修正值 = Σ(各修正来源)
最终值 = 基础骰 + 修正值（钳制到 1-100）
```

### 6.2 五级结果
| 骰值 | 结果 | 含义 |
|------|------|------|
| 95+ | 大成功 | 超出预期，历史转折 |
| 70-94 | 成功 | 达成目标 |
| 40-69 | 部分成功 | 达成但有代价 |
| 10-39 | 失败 | 未达成 |
| 9 以下 | 大失败 | 灾难性后果 |

### 6.3 NPC 参数修正
| 参数 | 公式 | 说明 |
|------|------|------|
| 自主度 | autonomy × 3 | 越自主，行动越果断 |
| 风险容忍 | risk_tolerance × 20 | 越敢冒险，波动越大 |
| 主动性 | initiative × 15 | 越主动，越可能抓住机会 |
| 能力值 | competence × 25 | 越专业，执行质量越高 |

### 6.4 优势/劣势骰
- 优势：掷 2 个 d100，取较高值
- 劣势：掷 2 个 d100，取较低值
- 不叠加：同时有优势和劣势时互相抵消

### 6.5 应用场景
| 场景 | 函数 | 修正来源 |
|------|------|---------|
| 侦察检定 | `roll_scout_check()` | NPC 能力 + 距离 + 搜索模式 |
| 攻击检定 | `roll_attack_check()` | NPC 能力 + 目标状态 + 距离 |
| 天气检定 | `roll_weather_check()` | 季节（待实现） |
| 着舰检定 | `roll_landing_check()` | NPC 能力 + 天气 + 燃油 |

## 七、NPC 系统

### 7.1 NPC 列表
| NPC | 职位 | 自主度 | 风险容忍 | 能力 | 信息权限 |
|-----|------|--------|---------|------|---------|
| Browning | 参谋长 | 8 | 0.8 | 0.9 | 全局态势 |
| Murray | 企业号舰长 | 5 | 0.4 | 0.7 | 本舰 |
| Mitscher | 大黄蜂舰长 | 5 | 0.4 | 0.7 | 本舰 |
| 通信官 | 通信官 | 1 | 0.1 | 0.6 | 电报 |
| 情报官 | 情报参谋 | 3 | 0.3 | 0.7 | 情报 |

### 7.2 NPC 行为规则
- **Browning**：主动建议、分析情报、推荐搜索模式、直接执行命令
- **Murray/Mitscher**：只管本舰，被动报告
- **通信官**：只读电报，不做判断
- **情报官**：分析情报可信度，建议搜索方向

### 7.3 信息不对称
- 每个 NPC 只看到自己权限内的信息
- 侦察报告有失真（NPC 不知道）
- 玩家通过多个 NPC 的信息拼凑真相
- Browning 作为情报中介，分析报告可信度

## 八、地图系统

### 8.1 坐标系统
- 地理坐标（lat/lon）为真相源
- 六边形网格为显示辅助和空间判定
- 10nm/格，40格半径

### 8.2 显示元素
| 元素 | 渲染方式 |
|------|---------|
| 己方舰队 | SVG 航母图标 + 代号 + 航向箭头 |
| 敌军 | 红色虚线圈 + "?" + 置信度 |
| 侦察机 | 三角形编队 + 燃油% + 阶段 |
| 中途岛 | 环礁轮廓 + 两岛 + 跑道 |
| 搜索扇面 | 楔形半透明区域 |
| 距离环 | 圆形虚线 + 海里标注 |
| 罗盘 | 八角星 + N/S/E/W |
| 比例尺 | 0-25nm-50nm |
| 待确认方案 | 橙色虚线 + PENDING 印章 |

### 8.3 空间判定（SpatialIndex）
- 每 tick 更新实体位置到 hex 格子
- 支持查询：某格内实体、范围内实体、两实体距离
- 用于接敌判定、CAP 覆盖、武器范围
