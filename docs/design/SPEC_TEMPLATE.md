### 第4部分：规则（核心，最重要）

```markdown
### X.4 规则

> 每条规则必须：
> 1. 有唯一编号（前缀-NNN）
> 2. 格式：条件 → 行为 → 边界
> 3. 能直接翻译成一个 pytest 用例

| 系统 | 编号前缀 |
|------|---------|

| 地图系统 | MAP- |

#### 规则格式

每条规则用以下格式书写：

| 编号 | 规则 | 条件 | 行为 | 边界/异常 | 测试关联 |
|------|------|------|------|----------|---------|
| GEO-001 | 名称 | when X happens | then do Y | edge case Z | test_xxx.py::test_yyy |

#### 规则表格示例

| 编号 | 规则 | 条件 | 行为 | 边界/异常 | 测试关联 |
|------|------|------|------|----------|---------|
| GEO-001 | 坐标转hex | 输入 lat, lon | 转为 (q,r) hex坐标 | 纬度超出[-90,90]抛异常 | test_coordinate::test_world_to_hex |
| GEO-002 | hex转坐标 | 输入 (q,r) | 转为 (lat,lon) 中心点 | hex超出GRID_RADIUS返回None | test_coordinate::test_hex_to_world |
| GEO-003 | 坐标往返精度 | world_to_hex→hex_to_world | 误差<0.01°（≈0.6nm） | — | test_coordinate::test_roundtrip |
```

### 第5部分：算法与公式

```markdown
### X.5 算法与公式

> 所有计算必须写成可直接翻译为代码的伪代码。

#### X.5.1 [算法名称]

**用途**：一句话说明
**输入**：参数名、类型、范围
**输出**：返回值、类型、范围

**公式**：
```
result = base + modifier1 × weight1 + modifier2 × weight2
result = clamp(result, min, max)
```

**伪代码**：
```python
def algorithm_name(param1: float, param2: int) -> float:
    """
    Args:
        param1: 说明, range [0, 1]
        param2: 说明, range [1, 100]
    Returns:
        说明, range [min, max]
    """
    base = param1 × 100
    modifier = param2 × WEIGHT
    result = base + modifier
    return clamp(result, 0, 100)
```

**边界条件**：
- param1 = 0 时：返回值 = ...
- param1 = 1 时：返回值 = ...
- param2 = 0 时：返回值 = ...
```

```markdown
### X.7 边界条件与异常

| 编号 | 场景 | 预期行为 | 降级策略 |
|------|------|---------|---------|
| X-EDGE-001 | 描述 | 正确行为 | 如果失败则... |
| X-EDGE-002 | 描述 | 正确行为 | 如果失败则... |

**异常处理原则**：
- 输入非法：抛 ValueError，不静默忽略
- 状态不合法：抛 RuntimeError，不自动修复
- 外部依赖失败（LLM）：返回降级结果，记录日志
```

## 附加：每系统检查清单

每个系统规格完成后，用此清单自检：

- [ ] **完整性**：8 个部分全部填写，无省略
- [ ] **无歧义**：每条规则只有一种理解方式
- [ ] **可测试**：每条规则可翻译为至少一个 pytest
- [ ] **无矛盾**：规则之间不冲突
- [ ] **边界覆盖**：每个公式有最小/最大/临界值说明
- [ ] **异常覆盖**：每个接口有异常处理说明
- [ ] **测试矩阵**：规则编号 → 测试函数 100% 映射
- [ ] **状态机完整**：每个状态都有出路（无死锁状态）
- [ ] **接口明确**：输入/输出/副作用全部说明
- [ ] **视觉规范**：每个数据类型有对应的渲染规则
