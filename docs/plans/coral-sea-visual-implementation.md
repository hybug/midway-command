日期：2026-11-19\
状态：实施规格。画面数值为设计目标，须经首轮合成和浏览器截图验收。\
视觉依据：[A 旗舰指挥室](../assets/command-room/concept-flagship-command-post.png)、[B 珊瑚海海图](../assets/command-room/concept-coral-sea-chart.png)。\

## 1. 复现标准

两张已选图就是美术母版。构图、光线、画面层次、阴影、器材轮廓和桌框都以母版为准。可以直接使用的静态像素优先保留，生成式处理限定在指定修复区。所有实机视图都在母版坐标里排版，然后随画幅调整。

“100%”有两个可核查的含义：

- **冻结区域的源文件像素 100% 一致。** 在 1672×941 的无损合成母版上，修补区与动态区之外逐像素比较。灯具、隔舱、器材和桌框这些已认可的细节直接来自原图。
- **两张图的构图要点逐项通过。** 摄影视角、光色、物件位置、海图占比、电报轮廓、图记层级与操作位置都要验收。只要其中一项明显走样，就继续修，即便整体相似度看起来很高。

实机截图的岸线、图记、中文、电报内容和时间随场景变化。它们与概念图对应的是空间关系及视觉角色。静态素材检查以原图为基准，运行画面检查以浏览器中的实际数据和可交互控件为准。视觉验收以合成、浏览器和实际数据三项通过为准。

## 4. 切图、局部生图与回贴

### 手工处理顺序

1. 将原图置为只读底层，保持 sRGB、1672×941 与原始裁切。分别建立 `锁定区域`、`修复区域`、`运行动态区域` 标注；保留修复前后图及掩膜。源文件用 PNG 存档。
2. A 逐处擦除文字、导线和圆点。钢壁的同色区域优先用邻近像素修补。线条经过灯下海图、无线电或文件时，将修复框放大到可以看见接缝，结果仍按遮罩回贴。清理文字阴影和抗锯齿残边。
3. B 先分出整个框体，再提取电报与夹。纸边找真实外轮廓，成品使用 `trim` 边界加母版坐标复位。夹扣和纸主体各留 8–16px 透明安全边。地图背后原本被纸遮住的区域由实时地图自然补齐。
4. 纸中心对齐母版的浅米色。默认用固定外壳和内部滚动实现长正文。需要窄屏变体时可优先用 CSS 纸色与独立纸边。对边角有拉伸需求时按实际折角边界做九宫格，预留约 24px 源图边缘，并在实际尺寸检查。
5. 输出合成对照图。无损重组时，修复图只在允许的 Alpha 区域替换原图。生成工具提交的整图即使局部正确，也只取经审核的补丁像素。其余位置从原图拷回。

### AI 作业单

使用概念图作为编辑输入，按下列局部作业逐块处理。优先提交含上下文的局部图，回贴使用作业前登记的遮罩和原坐标。若几何边缘移动、纸纹变成新花纹或颜色拼缝明显，缩小遮罩，用邻近采样与手修收尾。

| 作业 | 何时使用 | 提示词与回贴验收 |
|---|---|---|
| G01 舱室去字 | 导线或标签压住复杂材质，手修难以连续 | `Remove only the selected lettering, leader line and dot. Continue the surrounding surface, lighting, perspective and any existing equipment edges through this small patch. Leave the remaining composition unchanged.` 每块回贴检查同一条边是否连续 |
| G02 海图框去字 | B 上方时间和下方按钮字压在有磨损的金属上 | `Remove only the selected UI lettering. Extend the adjacent dark painted steel and existing grain, highlights and patina into that area. Preserve the shape and edges of the original metal frame.` 按母版光照核对，不重画铆钉 |
| G03 电报纸补全 | 原字占据纸纤维，或夹扣下需补顶部纸边 | `Fill the selected labels and upper occluded portion with matching blank cream paper. Continue only the existing fiber texture and slight edge wear. No lettering, ruling, new folds or stains.` 输出纸边精修层，保留原折角与色差 |
| G04 海图中性纹理 | 母版中难以找到可平铺的无字纸纹 | `Evenly lit flat neutral archival plotting-chart paper fibers, fine grain, subtle texture, no text, map, ruling, stains, folds or directional shadows.` 生成后平铺检查，以实际渲染时的海域色验证 |

这轮的交付件是两张可运行的场景及其资产。舱室全景、旗舰额外场景、人物与过场美术使用后续独立画面规格。

## 5. 工程落地

### 5.1 图层与尺寸

```text
A  指挥室底图 → 局部状态灯 → DOM 热点及导线 → 时间与返回信息
B  海图底材 → 地理及态势 Canvas → 图面光照 → 前景框体
   → 选中导线 → 电报阴影、纸、金属夹 → 电报正文和控件
```

- 两屏共用 1672×941 设计空间。桌面按 `min(可用宽 / 1672, 可用高 / 941)` 等比适配，用暗色舱壁延展可用余量。画面、热区及标签使用同一个变换和偏移。相反方向的换算用于鼠标命中。
- 设计基准是完整画幅。16:9 视口保持构图。1440×900、1440×662 使用全画幅置中及周围暗边，确保角落的返回、时钟与三站仍在可视区。文字的可读尺寸单独约束，键盘目标在 CSS 像素中处理。
- 窄屏海图可将电报移入底部阅读层。文书打开时要能访问正文、关闭与下一步，地图可继续定位报告。桌面截图作为视觉复现基线，窄屏以功能验收。
- A 背景保留一张静态图。B 背景、框体、光照和电报分层。只在实时数据、视图变化或窗口尺寸变化时刷新绘图。两套画面切换使用短淡化与局部推进，保留立即切换的减少动态设置。

| 模块 | 实施任务 |

来报与标图的关联采用已核实的公开来源链。`/intel/inbox` 提供 `observed_at`、`received_at`、消息 ID、转呈链和已关联简报等字段。接入前验证已有公开证据与获准标图可以顺着同一 ID 链连接。若缺少关系，用已有证据来源补公开引用或显示「尚无关联标图」。未批准报告的候选位置仅在既有审核预览权限下显示。来报已阅、获批标图与命令签发各有自己的状态。

### 5.3 颜色与排版

B 母版单点采样可用作初始调色参考。`(1000,550)` 海面 `#7E9E9C`，`(900,800)` 暗海面 `#5B787D`，`(1300,555)` 纸面 `#DCCAB4`，`(1470,906)` 控制条底 `#1C1F22`。这些点含有母版环境照明。先合成海面和灯光，再检查成片取样，避免叠加后明暗过重。

海图使用冷青灰水域、暖浅陆地、细网格与深色图记。红色虚线配上「未核实」文字。控件字号按 CSS 像素做可用性检查，中文正文基准 16px，来源与时间约 13–14px。参考图给出信息秩序，实际中文长度用真实电文验证。

## 6. 顺序与交付件

| 批次 | 工作 | 产出与完成标准 |

| 1 母版标注 | 冻结源图和哈希，标注多边形、遮罩、锚点、清理范围 | A/B 原图注释及素材清单。所有热点和可裁剪部件有精确定位 |

## 7. 验收

### 7.1 母版与浏览器对照

| 检查 | 方法 | 合格条件 |
|---|---|---|
| 锁定像素 | 1672×941 无损合成，对原图与静态资产合成结果做掩膜异或差分 | 锁定区变动像素数为 0。压缩交付图另测观感，基准始终保存无损版本 |
| 构图 | A/B 在 1672×941、DPR 1 的统一浏览器基准截图上画 50% 透明叠图与差值图 | 静态框体、灯、纸和夹的主要锚点误差目标 ≤3 CSS px。标签锚点 ≤6 CSS px。实测截图按部件列结果 |
| 编辑区 | 放至 100% 和 200% 看深浅两侧接缝，再回到实际视口看 | 逐块检查残字、重影、纸边白线和可见色阶断层，任一缺陷可见即返修 |
| 光色 | 核对海面、纸、金属及亮暗过渡。实机图移除文字和地图几何差异后比对取样 | 静态灯光方向、暖色工作区与冷色环境一致。相同材质区建议 sRGB 各通道平均误差 ≤8，按区给差异报告 |
| 动态构图 | 固定一组获准公开的信息用于视觉测试，另走一局真实数据 | 没有文字遮海图重点。展开电报时，重点区、报告与选中标记仍有清楚的视觉联系 |

测试用电报可以复现第二张图的阅读密度与开合状态。它只在快照或独立预览中启用；正式画面从当局状态取数据。指定浏览器、系统字体、DPR、色彩设置、视口及资源版本。等待字体、地图和图片加载后再截图；冻结演示时间并关闭动效。

### 7.2 要保存的状态

| 状态 | 必查项 |

验收资料放入 `docs/reports/command-room/`，包含参考图、运行截图、带编号的小区域对照和每项结论。涉及行为时先补仓库要求的回归测试，再实现与浏览器验证。检查鼠标命中、键盘操作、尺寸变化、图片失败及接口失败。战中信息权限独立走回归测试。

如果画面差异超标，按来源修复。轮廓错位回到切图锚点，画面主体变小回到共同画幅变换，灯光拼接明显回到修复遮罩，地图偏移回到统一投影。结案以两张实机画面和实际操作为准。
