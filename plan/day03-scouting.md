# Day 3 · 侦察循环

**目标**：实现完整的侦察循环：玩家命令侦察 → NPC 执行 → 等待 → 报告到达。

**预估工作量**：5-6 小时

---

## 设计要点

**侦察流程**：
1. 玩家命令"派侦察机搜索西北"
2. NPC 理解命令，调用 `launch_scout`
3. 规则引擎创建 `ScoutMission`，记录搜索扇面、ETA
4. 玩家推进时间
5. ETA 到达时，掷骰子决定是否发现敌舰
6. 发现 → 报告到达（有延迟）
7. 未发现 → 报告"扇面内未发现敌舰"

**骰子检定**：
```
threshold = 50 + competence × 20 - distance_factor × 30
roll = d100
result = roll < threshold → 发现
```

**信息失真**：
- 位置误差：±20 海里
- 数量误差：可能少报（云层遮挡）
- 延迟：30-60 分钟
