# Day 8 · 战斗演算

**目标**：实现攻击结果和损失计算。

**预估工作量**：5-6 小时

---

## 设计要点

**攻击流程**：
1. 玩家决定攻击 → 攻击波出发
2. 飞行时间（60-90 分钟）
3. 攻击检定（骰子 + 修正值）
4. 损失计算（骰子 + 修正值）
5. 战果报告（延迟到达）

**攻击骰子**：
```
threshold = 40 + competence × 25 + surprise_bonus × 20
roll = d100
result = roll < threshold → 攻击成功
```

**损失计算**：
- 攻击成功：损失 10-30% 的飞机
- 攻击失败：损失 30-60% 的飞机
- 大失败：损失 60-90% 的飞机

**战果报告**：
- 延迟 60-90 分钟
- 报告内容有误差（击沉数、损伤程度）
- 多个攻击波的报告可能矛盾
