# Day 7 · 连锁事件

**目标**：实现连锁事件系统，前置事件触发后续事件。

**预估工作量**：4-5 小时

---

## 设计要点

**事件类型**：
| 类型 | 触发方式 | 例子 |
|------|---------|------|
| 历史事件 | 固定时间 | 中途岛遭袭（06:00） |
| 侦察事件 | 玩家行动触发 | PBY 发现敌舰 |
| 连锁事件 | 前置事件触发 | 攻击成功 → 日军反击 |

**连锁事件链示例**：
```
[04:00] 玩家派侦察机 → 侦察事件触发
[04:30] 中途岛遭袭 → 历史事件触发
[05:00] 侦察报告到达 → 侦察事件结果
[06:00] 玩家决定攻击 → 攻击事件触发
[07:30] 攻击结果报告 → 攻击事件结果
[08:00] 日军反击 → 连锁事件触发
```

**事件对状态的影响**：
| 事件 | 状态变化 | 信息变化 |
|------|---------|---------|
| 侦察发现敌舰 | `known_enemy` 增加 | 新增情报条目 |
| 中途岛遭袭 | `incoming_messages` 增加 | 新增电报 |
| 攻击成功 | `_hidden_actual_enemy` 损伤 | 可能有战果报告 |
| 日军反击 | 美军舰艇损伤 | 新增战斗报告 |
